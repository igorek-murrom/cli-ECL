# Конфигурационное управление. Домашняя работа, вариант 15

Утилита читает учебную конфигурацию из стандартного ввода в UTF-8
и выводит TOML в стандартный вывод. Синтаксис описан грамматикой
[config.lark](src/config.lark), которую разбирает Lark в режиме LALR.
Tomli-W записывает результат в TOML.

## Сборка и запуск

Нужны Python 3.11 или новее и оболочка POSIX. Для сборки достаточно создать
виртуальное окружение и установить зависимости из корня проекта.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

```sh
./run.sh --help
printf '%s\n' 'dict(port = 8080)' | ./run.sh
```

Сценарий запуска использует `.venv/bin/python`, если окружение создано,
или `python3`. Переменная окружения `PYTHON` позволяет указать другой
интерпретатор с установленными зависимостями. Параметры конфигурации
передаются через стандартный ввод. Опция `-h` или `--help` показывает справку.

```sh
.venv/bin/python -m unittest discover -s tests -v
```

## Синтаксис и преобразование

| Конструкция | Синтаксис и результат |
| --- | --- |
| Число | `42`, `-5.`, `.25`, `-1.2e+3`. В TOML целые и вещественные литералы сохраняют тип. |
| Строка | `@"Это строка"`. Содержимое однострочное и читается буквально. |
| Массив | `[1; @"текст"; dict(x = 3)]`. Элементы разделяются точкой с запятой. Пустой массив — `[]`. |
| Словарь | `dict(host = @"localhost", port = 8080)`. Поля разделяются запятыми. Пустой словарь — `dict()`. |
| Имя | `[a-z][a-z0-9_]*` для ключей словаря и констант. Например, `port_1`. |
| Объявление | `(define port 8080)` вычисляет и сохраняет значение во время трансляции. |
| Вычисление | `#{port}` подставляет значение ранее объявленной константы. |

Конфигурация состоит из объявлений констант и одного корневого значения.
Объявления необязательны и записываются перед корнем. Ссылки разрешены
везде, где ожидается значение. В словари и массивы можно вкладывать любые
значения. Разделители ставятся между элементами. Ключи должны быть уникальны
в пределах одного словаря, а имена констант — в пределах документа.
Обратная косая черта в строках сохраняется как обычный символ.
Закрывающая кавычка завершает строку.

Поля корневого словаря становятся полями TOML. Корневой массив, строка или
число записываются под ключом `value`. Объявления используются при подстановке
и в TOML не записываются. При ошибке утилита сообщает строку и столбец
в стандартном потоке ошибок и завершается с кодом 1. При успехе код выхода 0.

## Функции

| Функция | Назначение |
| --- | --- |
| `cli.main()` | Обрабатывает аргументы, читает stdin и записывает TOML или диагностику. |
| `cli.to_toml(text)` | Преобразует текст учебного языка в документ TOML. |
| `config_parser.parse_config(text)` | Разбирает входной текст и вычисляет корневое значение. |
| `config_parser._error(line, column, message)` | Создаёт ошибку с координатами. |
| `config_parser._syntax_error(text, error)` | Преобразует диагностику Lark в ошибку конфигурации. |

Методы обработчика грамматики `ConfigEvaluator` создают таблицу констант
(`__init__`), возвращают корневое значение (`start`), сохраняют и подставляют
константы (`definition`, `reference`), преобразуют литералы (`number`,
`string`), собирают массивы (`array`) и словари (`pair`, `dictionary`).

## Примеры

### Метеостанция

[Конфигурация метеостанции](examples/weather.cfg) задаёт интервал опроса
и диапазоны измерений датчиков. В результирующем TOML есть поля
`station`, `interval_seconds` и массив `sensors` со словарями датчиков.

```sh
./run.sh < examples/weather.cfg
```

### Библиотека

[Конфигурация библиотеки](examples/library.cfg) задаёт фонды, сроки выдачи,
варианты продления и точки получения книг. Результат содержит поле `branch`,
массив `catalogs` и таблицу `circulation`.

```sh
./run.sh < examples/library.cfg
```
